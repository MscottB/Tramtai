# Tramtai: contexto de producto

Tramtai es una pasarela local que convierte los CLI de IA instalados en el equipo (Claude Code, Codex CLI, Gemini CLI, Antigravity) en API compatibles con OpenAI, Anthropic y una API propia. Funciona como servicio en segundo plano, con Web UI, terminal y una app de escritorio con icono en la bandeja.

## Público y tareas

- Desarrolladores y usuarios avanzados, sobre todo en Windows, que quieren usar su suscripción o sus claves de los CLI desde sus propias aplicaciones.
- Tareas habituales: comprobar que el servicio y los agentes funcionan, probar un mensaje, crear y conectar API por aplicación (con instrucciones, modelo y esfuerzo propios), revisar el historial de peticiones y ajustar el servicio (puerto, arranque con Windows, borrado de datos).

## Compromisos

- Idiomas: español principal, inglés secundario; preparado para un tercero.
- Apariencia clara y oscura de igual calidad, más «como el sistema».
- Uso local y privado: las claves nunca se muestran ni viajan en URL; los tokens OAuth de los CLI nunca se leen ni se copian.
- Licencia propietaria.
- Dirección visual vigente: «Red de tranvía» (ver `.impeccable/superficie-web-ui.md`).

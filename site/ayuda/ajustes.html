Ajustes y actualizacionesSettings and updates

Arranque con el sistema, modelo predeterminado, archivos, historial y actualizaciones.Start with the system, default model, files, history and updates.

  1. Activa el arranque con el sistema: Tramtai se abre oculto en la bandeja al iniciar sesión.Turn on start with the system: Tramtai opens hidden in the tray when you sign in.
  2. Elige el modelo y el esfuerzo que se usan cuando una petición no los dice.Pick the model and effort used when a request does not say.
  3. En Historial decide cuánto se guardan las peticiones; en Archivos, prepara el conversor.In History decide how long requests are kept; in Files, prepare the converter.
¿Qué pasa al actualizar?What happens when I update?

El aviso muestra lo que trae cada versión. En Windows se instala sola y la app vuelve a abrirse con tus datos; en el resto, el aviso trae el enlace.The notice shows what each version brings. On Windows it installs itself and the app reopens with your data; elsewhere, the notice has the link.

¿Cómo actualizo en macOS y Linux?How do I update on macOS and Linux?

Con Homebrew, «brew upgrade». El .dmg, .deb, .rpm y la portable: instala el paquete nuevo encima. En la terminal, «tramtai actualizar».With Homebrew, "brew upgrade". The .dmg, .deb, .rpm and portable: install the new package on top. In the terminal, "tramtai actualizar".

¿Puedo buscar una versión ahora?Can I check for a version now?

Sí: «Buscar actualización ahora» en Ajustes. Tramtai también mira cada hora; solo pide a GitHub la ficha pública de la última versión.Yes: "Check for updates now" in Settings. Tramtai also checks every hour; it only asks GitHub for the latest release’s public page.

¿Qué versión tengo?Which version do I have?

Abre «Acerca de Tramtai» en el menú lateral o en la bandeja; «Copiar datos para soporte» copia lo necesario sin claves.Open "About Tramtai" in the side menu or the tray; "Copy support data" copies what is needed, without keys.

¿Dónde se guardan mis datos?Where is my data kept?

Solo en este equipo, en la carpeta de Tramtai. Las respuestas se guardan 24 horas y el resto, 7 días; se cambia en Ajustes → Historial.Only on this computer, in Tramtai’s folder. Answers are kept 24 hours and the rest 7 days; change it in Settings → History.

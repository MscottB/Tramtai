ConceptosConcepts

Las palabras que usa Tramtai, en una línea cada una.The words Tramtai uses, one line each.

PreguntasQuestions

AgenteAgent

El programa de IA que responde: Claude Code, Codex, GitHub Copilot, la API de Gemini o Antigravity. Se conecta en Agentes, con tu suscripción o una clave de API.The AI program that answers: Claude Code, Codex, GitHub Copilot, the Gemini API or Antigravity. Connect it in Agents, with your subscription or an API key. Agentes y modelosAgents and models →

ModeloModel

El modelo que usa el agente (sonnet, opus, gpt-5.5…). Se escribe agente/modelo; la lista muestra la versión exacta que hay detrás.The model the agent uses (sonnet, opus, gpt-5.5…). It is written agent/model; the list shows the exact version behind it. Agentes y modelosAgents and models →

PerfilProfile

Un atajo como perfil/rapido o perfil/profundo que elige el modelo adecuado del agente predeterminado, sin escribir su nombre.A shortcut like perfil/rapido or perfil/profundo that picks the right model of the default agent, without typing its name. Agentes y modelosAgents and models →

EsfuerzoEffort

Cuánto razona el modelo antes de responder, de bajo a máximo. Más esfuerzo da mejores respuestas difíciles, pero tarda más y gasta más tokens. En Ajustes eliges el del modelo predeterminado.How hard the model reasons before answering, from low to max. More effort gives better answers to hard questions but takes longer and uses more tokens. ProbarTry →

RecetaRecipe

Lo que define cómo responde una API: instrucciones, agente y modelo, esfuerzo, respaldo y esquema JSON. Se prueba en Probar.What defines how an API answers: instructions, agent and model, effort, fallback and JSON schema. You test it in Try. Recetas y respaldoRecipes and fallback →

RespaldoFallback

Hasta 3 agentes de reserva que siguen la petición si el principal falla antes de empezar a responder.Up to 3 backup agents that take over the request if the main one fails before it starts answering. Recetas y respaldoRecipes and fallback →

Clave del espacio y APIs por aplicaciónWorkspace key and per-app APIs

La principal sirve para todo con una sola clave. Una API por aplicación tiene su URL, su clave, su receta y su presupuesto.The main one serves everything with a single key. A per-app API has its own URL, key, recipe and budget. Conectar mi appConnect my app →

PeticiónRequest

Cada mensaje enviado a un agente, desde Probar, la terminal o una app. Queda en el Historial con su respuesta y su registro.Each message sent to an agent, from Try, the terminal or an app. It stays in the History with its answer and its log. HistorialHistory →

Respuesta con forma (esquema JSON)Shaped response (JSON schema)

La forma que debe tener la respuesta: sus campos y su tipo. Si la respuesta no la cumple, la petición falla o se pide una corrección, en vez de entregar algo inesperado.The shape the answer must have: its fields and their type. If the answer does not match, the request fails or a correction is asked for, instead of delivering something unexpected. Respuestas JSONJSON answers →

ContextoContext

Cuánto texto acepta un modelo de una vez. Los documentos convertidos cuentan: si no caben, Tramtai lo dice antes de gastar tokens.How much text a model accepts at once. Converted documents count: if they do not fit, Tramtai says so before spending tokens. ArchivosFiles →

Espacio de trabajoWorkspace

Dónde se guardan las peticiones y las APIs: el global, o uno por proyecto con su propio historial.Where requests and APIs are kept: the global one, or one per project with its own history.

PresupuestoBudget

Límites por día y por mes en peticiones, tokens o dólares, para una API o para todo el espacio.Daily and monthly limits in requests, tokens or dollars, for one API or for the whole workspace. PresupuestosBudgets →

Cada API por aplicación tiene su dirección, su presupuesto y su historial: si una se filtra, revocas solo esa.Each per-app API has its own address, budget and history: if one leaks, you revoke only that one.

¿Qué clave le doy a mi app?Which key do I give my app?

Para probar, la del espacio. Para una app de verdad, créale su propia API en Mis APIs: la puedes limitar, medir y revocar sin tocar las demás.To try things, the workspace one. For a real app, create its own API in My APIs: you can limit, measure and revoke it without touching the rest.

¿Y si se filtra la clave del espacio?What if the workspace key leaks?

Regenérala en Mis APIs, pestaña «Clave del espacio»: la anterior deja de valer al momento. Las APIs por aplicación no cambian.Regenerate it in My APIs, “Workspace key” tab: the old one stops working at once. Per-app APIs do not change.

¿Por qué me sugiere crear una API?Why does it suggest creating an API?

Porque más de 20 peticiones de apps llegaron con la clave del espacio en 24 h. Es solo una sugerencia: todo sigue funcionando igual.Because more than 20 app requests used the workspace key in 24 h. It is only a suggestion: everything keeps working the same.

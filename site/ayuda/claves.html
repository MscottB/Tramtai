Claves y APIsKeys and APIs

La clave del espacio y las APIs por aplicación: cuándo usar cada una y qué pasa al regenerarlas.The workspace key and per-app APIs: when to use each one and what happens when you regenerate them.

PreguntasQuestions

¿Qué clave le doy a mi app?Which key do I give my app?

Para tus scripts y pruebas, la del espacio. Para una app de verdad, créale su propia API en Mis APIs: la puedes limitar, medir y revocar sin tocar las demás.For your scripts and tests, the workspace one. For a real app, create its own API in My APIs: you can limit, measure and revoke it without touching the rest.

¿Y si se filtra la clave del espacio?What if the workspace key leaks?

Regenérala en «Clave del espacio» de Mis APIs, o con «tramtai global token --rotar» («tramtai proyecto token --rotar» en un proyecto). La anterior deja de valer al momento; las demás APIs no cambian.Regenerate it in “Workspace key” in My APIs, or with “tramtai global token --rotar” (“tramtai proyecto token --rotar” in a project). The old one stops working at once. Per-app APIs do not change.

¿Dónde veo la clave del espacio?Where do I see the workspace key?

Solo al crearla o regenerarla. Un espacio nuevo no tiene clave: créala en «Clave del espacio» de Mis APIs o con «tramtai global token --rotar» («tramtai proyecto token --rotar» en un proyecto).Only when you create or regenerate it. A new workspace has no key: create it in “Workspace key” in My APIs or with “tramtai global token --rotar” (“tramtai proyecto token --rotar” in a project).

¿Y si uso la variable TRAMTAI_TOKEN_GLOBAL?What if I use the TRAMTAI_TOKEN_GLOBAL variable?

Esa clave no se crea ni se regenera desde Tramtai, ni desde la CLI: cámbiala en la variable. «tramtai global token» te dice de dónde viene.That key cannot be created or regenerated from Tramtai, nor from the CLI: change it in the variable. “tramtai global token” tells you where it comes from.

¿Por qué me sugiere crear una API?Why does it suggest creating an API?

Porque más de 20 peticiones de apps llegaron con la clave del espacio en 24 h. Es solo una sugerencia: todo sigue funcionando igual.Because more than 20 app requests used the workspace key in 24 h. It is only a suggestion: everything keeps working the same.

En la terminal: en Mis APIs (4), Enter abre una API y la tecla y copia su URL. ← → pasa a la clave del espacio: t la crea o la regenera y, mientras se ve la recién hecha, la tecla y la copia.In the terminal: in My APIs (4), Enter opens an API and the y key copies its URL. ← → goes to the workspace key: t creates or regenerates it and, while the new one is on screen, y copies it.

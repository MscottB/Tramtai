Respuestas JSONJSON responses

Pide la respuesta con una forma fija (un esquema JSON) y Tramtai la valida antes de entregarla.Ask for the response in a fixed shape (a JSON schema) and Tramtai validates it before handing it over.

Cómo funcionaHow it works

  1. 1. El esquemaThe schemaLos campos y su tipo, armados con plantillas o en JSON.The fields and their type, built from templates or in JSON.
  2. 2. El agenteThe agentResponde siguiendo la forma pedida.Answers following the requested shape.
  3. 3. La validaciónValidationTramtai comprueba cada campo, también los formatos: fecha, correo, URL…Tramtai checks every field, formats too: date, email, URL…
  4. 4. La correcciónCorrectionSi no cumple, puede pedir al mismo agente que la arregle, hasta 3 veces.If it does not match, it can ask the same agent to fix it, up to 3 times.

Paso a pasoStep by step

  1. En Probar, abre «Opciones de la receta» y activa «Respuesta con forma».In the Playground, open “Recipe options” and turn on “Shaped response”.
  2. Elige una plantilla (extraer datos, clasificar, resumen, tareas…) o añade tus campos con su tipo y descripción.Pick a template (extract data, classify, summary, tasks…) or add your fields with their type and description.
  3. Prueba: si no cumple, verás qué campo falló y el botón «Corregir».Test it: if it does not match, you will see which field failed and the “Correct” button.
  4. En «Si la respuesta no cumple» pide hasta 3 correcciones automáticas; cada una es otra petición.In “If the response does not match” ask for up to 3 automatic corrections; each one is another request.
  5. Pulsa «Guardar como API»: tu app recibirá siempre esa forma.Click “Save as API”: your app will always get that shape.

Por OpenAI el esquema va en response_format; por la API propia, en salida. Si la respuesta no cumple, llega 422 salida_no_cumple_esquema.Through OpenAI the schema goes in response_format; through the native API, in salida. If the response does not match, you get 422 salida_no_cumple_esquema.

PreguntasQuestions

¿Se comprueban los formatos?Are formats checked?

Sí: fecha, fecha y hora, correo, URL… Una fecha y hora sin zona horaria no cumple «date-time».Yes: date, date-time, email, URL… A date-time without a time zone does not match “date-time”.

¿Puedo escribir el esquema a mano?Can I write the schema by hand?

Sí, en la pestaña JSON de «Respuesta con forma». Si falla siempre, simplifícalo o aclara la descripción de los campos.Yes, in the JSON tab of “Shaped response”. If it keeps failing, simplify it or clarify the fields’ descriptions.

Si algo fallaIf something fails

La respuesta no cumple el JSON SchemaThe response does not match the JSON Schema salida_no_cumple_esquema
La respuesta no tenía la forma pedida. En Probar verás qué campo falló; «Corregir» pide al agente que la arregle. Si falla siempre, simplifica el esquema.The response did not have the requested shape. The Playground shows which field failed; “Correct” asks the agent to fix it. If it keeps failing, simplify the schema.

En la terminal: en «Respuesta con forma (JSON)» de Probar (3), n añade un campo y v enseña un ejemplo de respuesta; si no cumple, o pide la corrección.In the terminal: under “Shaped response (JSON)” in the Playground (3), n adds a field and v shows a sample response; if it does not match, o asks for a correction.

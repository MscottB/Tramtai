Algo fallóSomething failed

Los errores más comunes, con el mismo título que ves en la app, y qué hacer con cada uno.The most common errors, with the same title you see in the app, and what to do about each.

  1. Abre el Historial y pulsa la petición con error.Open History and click the request with the error.
  2. Busca su error aquí abajo: cada uno dice qué significa y qué hacer.Find its error below: each one says what it means and what to do.
  3. Abre «Registro» para ver con qué agente se intentó, los avisos y cuánto tardó.Open "Log" to see which agent was tried, the warnings and how long it took.
  4. Corrige la causa y pulsa «Reintentar».Fix the cause and click "Retry".
Sin conexiónOffline
El servicio no está en marcha. Abre la app o ejecuta «tramtai servicio iniciar»; con el arranque automático de Ajustes no vuelve a pasar.The service is not running. Open the app or run "tramtai servicio iniciar"; with start-up in Settings it won’t happen again.
Falta la clave o no es válidaThe key is missing or not valid no_autorizado
Revisa la clave en tu app: la del espacio o la de esa API. Si la regeneraste, la anterior ya no vale.Check the key in your app: the workspace one or that API’s. If you regenerated it, the old one no longer works.
El agente no tiene una sesión o clave válidaThe agent has no valid session or key autenticacion_agente
El agente no tiene sesión ni clave. En Agentes, inicia sesión en su CLI o guarda una clave de API.The agent has no session or key. In Agents, sign in to its CLI or save an API key.
El agente no está disponibleThe agent is not available agente_no_disponible
El CLI no está instalado o no se encuentra; Agentes dice cómo instalarlo. Antigravity, además, no se usa desde APIs.The CLI is not installed or cannot be found; Agents says how to install it. Antigravity also cannot be used from APIs.
Se alcanzó el límite de uso del proveedorThe provider usage limit was reached limite_uso_proveedor
Llegaste al límite de tu plan o de tu clave. Espera a que el proveedor lo reinicie o añade un respaldo a la receta.You hit your plan’s or key’s limit. Wait for the provider to reset it or add a fallback to the recipe.
Ese modelo no está disponibleThat model is not available modelo_no_disponible
Usa un modelo de la lista con el agente delante, por ejemplo claude/sonnet, o un perfil como perfil/rapido.Use a model from the list with the agent in front, for example claude/sonnet, or a profile like perfil/rapido.
Hay un parámetro que no se admiteA parameter is not supported parametro_no_soportado
Pediste algo que los agentes de terminal no pueden respetar (imágenes, n mayor que 1, stop…): quítalo. Uno desconocido se acepta con compatibilidad.modo_tolerante.You asked for something terminal agents cannot honor (images, n above 1, stop…): remove it. Unknown ones are accepted with compatibilidad.modo_tolerante.
La entrada no cabe en el modeloThe input does not fit in the model entrada_demasiado_grande
Los documentos no caben en el modelo. Envía menos páginas, divide el archivo o pon en el respaldo un modelo con más contexto.The documents do not fit the model. Send fewer pages, split the file or put a model with more context in the fallback.
Se agotó el presupuestoThe budget ran out presupuesto_agotado
Esa API o el espacio llegó a su límite (error 429). Espera al reinicio del día o del mes, o pulsa «Reiniciar consumo» en Mis APIs.That API or the workspace hit its limit (error 429). Wait for the day or month to reset, or click "Reset usage" in My APIs.
La respuesta no cumple el JSON SchemaThe response does not match the JSON Schema salida_no_cumple_esquema
La respuesta no tenía la forma pedida. En Probar verás qué campo falló; «Corregir» pide al agente que la arregle. Si falla siempre, simplifica el esquema.The answer did not have the requested shape. Try shows which field failed; "Correct" asks the agent to fix it. If it keeps failing, simplify the schema.
Se agotó el tiempo límiteThe time limit ran out tiempo_ejecucion_agotado
Tardó más que el tiempo límite. Súbelo en las opciones avanzadas de Probar o en la petición, o baja el esfuerzo.It took longer than the time limit. Raise it in Try’s advanced options or in the request, or lower the effort.
La cola está llena; inténtalo en un momentoThe queue is full; try again shortly cola_llena
Hay demasiadas peticiones a la vez. Reintenta en unos segundos: la respuesta trae Retry-After con la espera.Too many requests at once. Retry in a few seconds: the response carries Retry-After with the wait.
No se pudo convertir el archivoThe file could not be converted conversion_fallida
No se pudo convertir un archivo. Comprueba que no esté dañado ni protegido con contraseña y que su formato se admita.A file could not be converted. Check that it is not damaged or password-protected and that its format is accepted.
Falta el conversor de archivosThe file converter is missing conversor_no_disponible
Falta el conversor de archivos: Ajustes → Archivos → «Preparar archivos». Si tu red bloquea la descarga, usa el paquete del conversor para Windows.The file converter is missing: Settings → Files → "Prepare files". If your network blocks the download, use the converter package for Windows.
El agente devolvió un errorThe agent returned an error error_agente
El agente falló al responder. Abre «Registro» para ver su mensaje; reintenta, o pon un respaldo en la receta para que siga otro agente.The agent failed while answering. Open "Log" to see its message; retry, or add a fallback to the recipe so another agent takes over.
No se entendió la respuesta del agenteThe agent response could not be understood error_protocolo_agente
El CLI respondió algo que Tramtai no entiende; suele pasar tras actualizar el CLI. Actualiza Tramtai o prueba con otro agente.The CLI answered something Tramtai does not understand; it usually happens after updating the CLI. Update Tramtai or try another agent.
Esperó demasiado en la colaIt waited too long in the queue tiempo_cola_agotado
La petición esperó demasiado su turno porque había muchas a la vez. Reintenta en un momento o envía menos peticiones juntas.The request waited too long for its turn because there were many at once. Retry in a moment or send fewer requests together.
Esa API no permite ese modeloThat API does not allow that model modelo_no_permitido
Esa API solo admite ciertos modelos. Usa uno de los suyos o añade ese modelo a sus permitidos en Mis APIs.That API only accepts certain models. Use one of its own or add that model to its allowed list in My APIs.
No hay un modelo configurado para ese perfilNo model is configured for that profile modelo_no_configurado
El perfil pedido (por ejemplo perfil/rapido) no tiene modelo para ese agente. Elige un modelo concreto, como claude/sonnet.The requested profile (for example perfil/rapido) has no model for that agent. Pick a specific model, like claude/sonnet.
Se llenó el espacio para archivosThe space for files is full cuota_cargas_agotada
Se llenó el espacio para archivos subidos. Espera a que venzan los anteriores o borra datos en Ajustes.The space for uploaded files is full. Wait for older ones to expire or delete data in Settings.

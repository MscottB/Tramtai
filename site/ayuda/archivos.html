ArchivosFiles

Tramtai convierte tus PDF, Word, Excel y otros documentos a texto antes de pasárselos al agente.Tramtai turns your PDF, Word, Excel and other documents into text before handing them to the agent.

Cómo funcionaHow it works

  1. 1. Tu app lo mandaYour app sends itPor la API propia, subiéndolo a /cargas; por OpenAI o Anthropic, en base64 dentro del mensaje.Through the native API, uploading it to /cargas; through OpenAI or Anthropic, in base64 inside the message.
  2. 2. Tramtai lo guardaTramtai keeps itComo una carga identificada por su contenido: el mismo archivo no se guarda dos veces.As an upload identified by its content: the same file is never stored twice.
  3. 3. Lo convierte a textoTurns it into textmarkitdown pasa PDF, Word, PowerPoint, Excel y HTML a Markdown; el texto va tal cual.markitdown turns PDF, Word, PowerPoint, Excel and HTML into Markdown; text goes as is.
  4. 4. Se lo da al agenteHands it to the agentUn bloque delimitado por archivo, junto con tu mensaje. El agente no lee tu disco.One delimited block per file, with your message. The agent does not read your disk.
  5. 5. Recibes la respuestaYou get the answerComo cualquier otra petición, en el formato de la API que usaste.Like any other request, in the format of the API you used.

Paso a pasoStep by step

  1. Por la API propia: sube cada archivo con POST /cargas y crea la petición citando sus cargas.Native API: upload each file with POST /cargas and create the request citing its uploads.
  2. Por OpenAI o Anthropic: pon el archivo en base64 dentro del mensaje (file, input_file o document).OpenAI or Anthropic: put the file in base64 inside the message (file, input_file or document).
  3. En Probar también puedes adjuntarlos para ver la respuesta antes.In Try you can attach them too, to see the answer first.

EjemploExample

# 1. Sube cada archivo y guarda su identificador (jq saca el campo de la respuesta JSON)
CARGAS=""
for ARCHIVO in 'informe.pdf'; do
  ID=$(curl -s http://127.0.0.1:17373/api/v1/cargas -H "Authorization: Bearer <tu clave>" -F "archivo=@\"$ARCHIVO\"" | jq -r .identificador_carga)
  CARGAS="$CARGAS${CARGAS:+,}\"$ID\""
done

# 2. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla

  -H "Content-Type: application/json" -H "Idempotency-Key: $(date +%s)" \
  -d '{
  "mensajes": [
    {
      "rol": "usuario",
      "contenido": "Resume el documento adjunto en una frase."
    }
  ],
  "cargas": ['"$CARGAS"']
}' | jq -r .id)

# 3. Síguela en vivo hasta el evento «fin» (si la cortas, la petición sigue y puedes volver con Last-Event-ID)

import json, sys, uuid
import requests

BASE = "http://127.0.0.1:17373/api/v1"
CABECERAS = {"Authorization": "Bearer <tu clave>"}

# 1. Sube cada archivo y guarda su identificador
cargas = []
for nombre in ["informe.pdf"]:
    with open(nombre, "rb") as f:
        r = requests.post(f"{BASE}/cargas", headers=CABECERAS, files={"archivo": f})
    if not r.ok:
        sys.exit(r.text)
    cargas.append(r.json()["identificador_carga"])

# 2. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla
solicitud = {
    "mensajes": [
        {
            "rol": "usuario",
            "contenido": "Resume el documento adjunto en una frase.",
        },
    ],
    "cargas": cargas,
}
r = requests.post(f"{BASE}/trabajos", headers={**CABECERAS, "Idempotency-Key": str(uuid.uuid4())}, json=solicitud)
if not r.ok:
    sys.exit(r.text)
trabajo = r.json()["id"]

# 3. Síguela en vivo: cada evento «texto» trae un trozo de la respuesta y «fin» cierra el flujo
fin, evento, datos = {}, "", []
with requests.get(f"{BASE}/trabajos/{trabajo}/eventos", headers=CABECERAS, stream=True) as eventos:
    for linea in (l.decode("utf-8") for l in eventos.iter_lines()):
        if linea.startswith("event: "):
            evento = linea[7:]
        elif linea.startswith("data: "):
            datos.append(linea[6:])
        elif linea == "" and evento:
            if evento == "texto":
                print("\n".join(datos), end="", flush=True)
            elif evento == "fin":
                fin = json.loads("\n".join(datos))
                break
            evento, datos = "", []
if fin.get("estado") != "completado":
    sys.exit(f"\n{fin}")

# 4. Lee el resultado (con esquema, el JSON ya validado)
print("\n" + requests.get(f"{BASE}/trabajos/{trabajo}/salida", headers=CABECERAS).content.decode("utf-8"))

import { readFile } from 'node:fs/promises'
import { basename } from 'node:path'
import { randomUUID } from 'node:crypto'

const BASE = 'http://127.0.0.1:17373/api/v1'
const cabeceras = { Authorization: 'Bearer <tu clave>' }
async function pedir(ruta, opciones = {}) {
  const r = await fetch(BASE + ruta, { ...opciones, headers: { ...cabeceras, ...opciones.headers } })
  if (!r.ok) throw new Error(await r.text())
  return r
}

// 1. Sube cada archivo y guarda su identificador
const cargas = []
for (const nombre of ["informe.pdf"]) {
  const datos = new FormData()
  datos.append('archivo', new Blob([await readFile(nombre)]), basename(nombre))
  cargas.push((await (await pedir('/cargas', { method: 'POST', body: datos })).json()).identificador_carga)
}

// 2. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla
const solicitud = {
  "mensajes": [
    {
      "rol": "usuario",
      "contenido": "Resume el documento adjunto en una frase."
    }
  ],
  "cargas": cargas
}
const { id } = await (await pedir('/trabajos', { method: 'POST', body: JSON.stringify(solicitud),
  headers: { 'Content-Type': 'application/json', 'Idempotency-Key': randomUUID() } })).json()

// 3. Síguela en vivo: cada evento «texto» trae un trozo de la respuesta y «fin» cierra el flujo
const eventos = await pedir(`/trabajos/${id}/eventos`)
const lector = new TextDecoder()
let pendiente = '', fin
for await (const trozo of eventos.body) {
  pendiente += lector.decode(trozo, { stream: true })
  let corte
  while ((corte = pendiente.indexOf('\n\n')) >= 0) {
    const bloque = pendiente.slice(0, corte).split('\n')
    pendiente = pendiente.slice(corte + 2)
    const evento = bloque.find((l) => l.startsWith('event: '))?.slice(7)
    const datos = bloque.filter((l) => l.startsWith('data: ')).map((l) => l.slice(6)).join('\n')
    if (evento === 'texto') process.stdout.write(datos)
    if (evento === 'fin') fin = JSON.parse(datos)
  }
}
if (fin?.estado !== 'completado') throw new Error(JSON.stringify(fin))

// 4. Lee el resultado (con esquema, el JSON ya validado)
console.log('\n' + await (await pedir(`/trabajos/${id}/salida`)).text())

package main

import (
	"bufio"
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"mime/multipart"
	"net/http"
	"os"
	"path/filepath"
	"strings"
)

const base = "http://127.0.0.1:17373/api/v1"

// pedir hace una petición con la clave y falla si la respuesta no es 2xx.
func pedir(metodo, ruta, tipo string, cuerpo io.Reader) *http.Response {
	peticion, err := http.NewRequest(metodo, base+ruta, cuerpo)
	if err != nil {
		log.Fatal(err)
	}
	peticion.Header.Set("Authorization", "Bearer <tu clave>")
	if tipo != "" {
		peticion.Header.Set("Content-Type", tipo)
	}
	respuesta, err := http.DefaultClient.Do(peticion)
	if err != nil {
		log.Fatal(err)
	}
	if respuesta.StatusCode >= 300 {
		datos, _ := io.ReadAll(respuesta.Body)
		log.Fatalf("%s: %s", respuesta.Status, datos)
	}
	return respuesta
}

func main() {
	// 1. Sube cada archivo y guarda su identificador
	var cargas []string
	for _, nombre := range []string{"informe.pdf"} {
		var cuerpo bytes.Buffer
		formulario := multipart.NewWriter(&cuerpo)
		parte, _ := formulario.CreateFormFile("archivo", filepath.Base(nombre))
		datos, err := os.ReadFile(nombre)
		if err != nil {
			log.Fatal(err)
		}
		parte.Write(datos)
		formulario.Close()
		var carga struct {
			ID string `json:"identificador_carga"`
		}
		json.NewDecoder(pedir("POST", "/cargas", formulario.FormDataContentType(), &cuerpo).Body).Decode(&carga)
		cargas = append(cargas, carga.ID)
	}

	// 2. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla
	solicitud := "{\"mensajes\":[{\"rol\":\"usuario\",\"contenido\":\"Resume el documento adjunto en una frase.\"}],\"cargas\":\"__CARGAS__\"}"
	lista, _ := json.Marshal(cargas)
	solicitud = strings.Replace(solicitud, "\"__CARGAS__\"", string(lista), 1)
	var trabajo struct {
		ID string `json:"id"`
	}
	json.NewDecoder(pedir("POST", "/trabajos", "application/json", strings.NewReader(solicitud)).Body).Decode(&trabajo)

	// 3. Síguela en vivo: cada evento «texto» trae un trozo de la respuesta y «fin» cierra el flujo
	eventos := bufio.NewScanner(pedir("GET", "/trabajos/"+trabajo.ID+"/eventos", "", nil).Body)
	evento := ""
	for eventos.Scan() {
		linea := eventos.Text()
		switch {
		case strings.HasPrefix(linea, "event: "):
			evento = linea[7:]
		case strings.HasPrefix(linea, "data: ") && evento == "texto":
			fmt.Print(linea[6:])
		case strings.HasPrefix(linea, "data: ") && evento == "fin":
			fmt.Println("\n" + linea[6:])
		}
	}

	// 4. Lee el resultado (con esquema, el JSON ya validado)
	salida, _ := io.ReadAll(pedir("GET", "/trabajos/"+trabajo.ID+"/salida", "", nil).Body)
	fmt.Println(string(salida))
}

import base64
import anthropic

# documento lee un archivo y lo deja como bloque del mensaje, en base64 (Tramtai lo convierte a texto para el agente).
def documento(nombre, tipo):

PreguntasQuestions

¿Puedo enviar imágenes?Can I send images?

Todavía no. Por OpenAI y Anthropic el archivo va dentro del mensaje: Tramtai no descarga URL ni usa file_id.Not yet. Through OpenAI and Anthropic the file goes inside the message: Tramtai does not download URLs or use file_id.

¿Por qué se rechazó mi petición por tamaño?Why was my request rejected for its size?

Lo que recibiría el agente no cabe en el modelo. Envía menos páginas o divide el archivo; el registro dice cuál pesa más. No se gastan tokens.What the agent would get does not fit the model. Send fewer pages or split the file; the log says which one weighs most. No tokens are spent.

¿Qué hago si falta el conversor?What if the converter is missing?

Ajustes → Archivos → «Preparar archivos», o «tramtai conversor preparar». Si tu red bloquea la descarga, usa el paquete del conversor para Windows.Settings → Files → "Prepare files", or "tramtai conversor preparar". If your network blocks the download, use the converter package for Windows.

¿Sale algo de mi equipo al convertir?Does anything leave my computer when converting?

No: markitdown corre en tu equipo. El texto convertido lo recibe el agente, como cualquier mensaje.No: markitdown runs on your computer. The converted text goes to the agent, like any message.

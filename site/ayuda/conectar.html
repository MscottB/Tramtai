Conectar mi appConnect my app

Cambia la URL base de tu SDK de OpenAI o Anthropic por la de Tramtai y elige el agente con model.Change your OpenAI or Anthropic SDK’s base URL to Tramtai’s and pick the agent with model.

Cómo funcionaHow it works

  1. 1. Tu appYour appCon el SDK de OpenAI, el de Anthropic o la API propia.With the OpenAI SDK, the Anthropic SDK or the native API.
  2. 2. URL y claveURL and keyLas de Mis APIs: la clave del espacio o una API por aplicación.The ones from My APIs: the workspace key or one API per app.
  3. 3. TramtaiTramtaiAplica la receta de esa API y pone la petición en la cola.Applies that API’s recipe and puts the request in the queue.
  4. 4. El agenteThe agentEl que diga model, por ejemplo claude/sonnet o perfil/rapido.The one model names, for example claude/sonnet or perfil/rapido.

Paso a pasoStep by step

  1. En Mis APIs, pestaña «Clave del espacio», copia la URL para OpenAI (o Anthropic) y la clave.In My APIs, “Workspace key” tab, copy the URL for OpenAI (or Anthropic) and the key.
  2. En tu app cambia la URL base (base_url) y la clave (api_key) por las de Tramtai.In your app change the base URL (base_url) and the key (api_key) to Tramtai’s.
  3. En model pon agente y modelo, por ejemplo claude/sonnet, o un perfil como perfil/rapido.In model put agent and model, for example claude/sonnet, or a profile like perfil/rapido.
  4. Envía una petición: aparece en el Historial con el agente que respondió.Send a request: it shows up in History with the agent that answered.

Qué verás en pantallaWhat you will see on screen

  1. La clave del espacioThe workspace key Cada espacio tiene una clave con acceso a cualquier agente y modelo: la usan la CLI de Tramtai, tus scripts y Probar. Tus apps van mejor con una API propia cada una.Each workspace has a key with access to any agent and model: the CLI, your scripts and the Playground use it. Your apps are better off with an API of their own each.
  2. Una API por aplicaciónOne API per app Con este botón creas una API para una app, con su dirección, su clave, sus modelos y su historial. Si una clave se filtra, revocas solo esa.This button creates an API for an app, with its own address, key, models and history. If a key leaks, you revoke only that one.
  3. Tus APIsYour APIs Aquí ves las APIs que has creado. Ábrelas para copiar su dirección y su clave, ver su uso o cambiar sus ajustes.Here you see the APIs you have created. Open one to copy its address and key, see its usage or change its settings.

import json, sys, uuid
import requests

BASE = "http://127.0.0.1:17373/api/v1"
CABECERAS = {"Authorization": "Bearer <tu clave>"}

# 1. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla
solicitud = {
    "mensajes": [
        {
            "rol": "usuario",
            "contenido": "Resume el documento adjunto en una frase.",
        },
    ],
}
r = requests.post(f"{BASE}/trabajos", headers={**CABECERAS, "Idempotency-Key": str(uuid.uuid4())}, json=solicitud)
if not r.ok:
    sys.exit(r.text)
trabajo = r.json()["id"]

# 2. Síguela en vivo: cada evento «texto» trae un trozo de la respuesta y «fin» cierra el flujo
fin, evento, datos = {}, "", []
with requests.get(f"{BASE}/trabajos/{trabajo}/eventos", headers=CABECERAS, stream=True) as eventos:
    for linea in (l.decode("utf-8") for l in eventos.iter_lines()):
        if linea.startswith("event: "):
            evento = linea[7:]
        elif linea.startswith("data: "):
            datos.append(linea[6:])
        elif linea == "" and evento:
            if evento == "texto":
                print("\n".join(datos), end="", flush=True)
            elif evento == "fin":
                fin = json.loads("\n".join(datos))
                break
            evento, datos = "", []
if fin.get("estado") != "completado":
    sys.exit(f"\n{fin}")

# 3. Lee el resultado (con esquema, el JSON ya validado)
print("\n" + requests.get(f"{BASE}/trabajos/{trabajo}/salida", headers=CABECERAS).content.decode("utf-8"))

import { randomUUID } from 'node:crypto'

const BASE = 'http://127.0.0.1:17373/api/v1'
const cabeceras = { Authorization: 'Bearer <tu clave>' }
async function pedir(ruta, opciones = {}) {
  const r = await fetch(BASE + ruta, { ...opciones, headers: { ...cabeceras, ...opciones.headers } })
  if (!r.ok) throw new Error(await r.text())
  return r
}

// 1. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla
const solicitud = {
  "mensajes": [
    {
      "rol": "usuario",
      "contenido": "Resume el documento adjunto en una frase."
    }
  ]
}
const { id } = await (await pedir('/trabajos', { method: 'POST', body: JSON.stringify(solicitud),
  headers: { 'Content-Type': 'application/json', 'Idempotency-Key': randomUUID() } })).json()

// 2. Síguela en vivo: cada evento «texto» trae un trozo de la respuesta y «fin» cierra el flujo
const eventos = await pedir(`/trabajos/${id}/eventos`)
const lector = new TextDecoder()
let pendiente = '', fin
for await (const trozo of eventos.body) {
  pendiente += lector.decode(trozo, { stream: true })
  let corte
  while ((corte = pendiente.indexOf('\n\n')) >= 0) {
    const bloque = pendiente.slice(0, corte).split('\n')
    pendiente = pendiente.slice(corte + 2)
    const evento = bloque.find((l) => l.startsWith('event: '))?.slice(7)
    const datos = bloque.filter((l) => l.startsWith('data: ')).map((l) => l.slice(6)).join('\n')
    if (evento === 'texto') process.stdout.write(datos)
    if (evento === 'fin') fin = JSON.parse(datos)
  }
}
if (fin?.estado !== 'completado') throw new Error(JSON.stringify(fin))

// 3. Lee el resultado (con esquema, el JSON ya validado)
console.log('\n' + await (await pedir(`/trabajos/${id}/salida`)).text())

package main

import (
	"bufio"
	"encoding/json"
	"fmt"
	"io"
	"log"
	"net/http"
	"strings"
)

const base = "http://127.0.0.1:17373/api/v1"

// pedir hace una petición con la clave y falla si la respuesta no es 2xx.
func pedir(metodo, ruta, tipo string, cuerpo io.Reader) *http.Response {
	peticion, err := http.NewRequest(metodo, base+ruta, cuerpo)
	if err != nil {
		log.Fatal(err)
	}
	peticion.Header.Set("Authorization", "Bearer <tu clave>")
	if tipo != "" {
		peticion.Header.Set("Content-Type", tipo)
	}
	respuesta, err := http.DefaultClient.Do(peticion)
	if err != nil {
		log.Fatal(err)
	}
	if respuesta.StatusCode >= 300 {
		datos, _ := io.ReadAll(respuesta.Body)
		log.Fatalf("%s: %s", respuesta.Status, datos)
	}
	return respuesta
}

func main() {
	// 1. Crea la petición; repetir la Idempotency-Key devuelve la misma petición en lugar de duplicarla
	solicitud := "{\"mensajes\":[{\"rol\":\"usuario\",\"contenido\":\"Resume el documento adjunto en una frase.\"}]}"
	var trabajo struct {
		ID string `json:"id"`
	}
	json.NewDecoder(pedir("POST", "/trabajos", "application/json", strings.NewReader(solicitud)).Body).Decode(&trabajo)

	// 2. Síguela en vivo: cada evento «texto» trae un trozo de la respuesta y «fin» cierra el flujo
	eventos := bufio.NewScanner(pedir("GET", "/trabajos/"+trabajo.ID+"/eventos", "", nil).Body)
	evento := ""
	for eventos.Scan() {
		linea := eventos.Text()
		switch {
		case strings.HasPrefix(linea, "event: "):
			evento = linea[7:]
		case strings.HasPrefix(linea, "data: ") && evento == "texto":
			fmt.Print(linea[6:])
		case strings.HasPrefix(linea, "data: ") && evento == "fin":
			fmt.Println("\n" + linea[6:])
		}
	}

	// 3. Lee el resultado (con esquema, el JSON ya validado)
	salida, _ := io.ReadAll(pedir("GET", "/trabajos/"+trabajo.ID+"/salida", "", nil).Body)
	fmt.Println(string(salida))
}

Las URL de OpenAI y Anthropic imitan esos servicios para que sus SDK funcionen igual, así que no tienen campos para seguir o cancelar una petición. PreguntasQuestions

¿Qué URL uso?Which URL do I use?

La de OpenAI si tu app usa su SDK o deja cambiar la URL base (LangChain, n8n); la de Anthropic con su SDK; la API propia para peticiones largas o para cancelar.OpenAI’s if your app uses its SDK or lets you change the base URL (LangChain, n8n); Anthropic’s with its SDK; the native API for long requests or to cancel.

¿Para qué sirve una API por aplicación?What is an API per app for?

Cada app tiene su clave, sus modelos, instrucciones fijas y presupuesto, y solo ve sus peticiones. Se activan o detienen sin reiniciar.Each app gets its key, its models, fixed instructions and budget, and only sees its own requests. They start or stop without restarting.

¿Dónde está la clave de una API nueva?Where is a new API’s key?

Solo se muestra al crearla: cópiala entonces. Si la pierdes, «Regenerar la clave» te da otra.It is shown only when created: copy it then. If you lose it, “Regenerate the key” gives you another.

¿Cómo convierto una prueba en una API?How do I turn a test into an API?

En Probar, «Guardar como API» te da URL y clave. Desde Mis APIs, «Abrir en Probar» la carga para cambiarla y «Guardar cambios» la guarda.In the Playground, “Save as API” gives you a URL and a key. From My APIs, “Open in the Playground” loads it to change it and “Save changes” saves it.

¿Qué hago si se filtra una clave?What if a key leaks?

En Mis APIs, «Regenerar la clave»: la anterior deja de valer al momento. Si es de un proveedor, revócala en su consola y guarda la nueva.In My APIs, “Regenerate the key”: the old one stops working at once. If it is a provider’s, revoke it in their console and save the new one.

¿Mi app puede ver lo que pasa en vivo?Can my app see what happens live?

Sí: GET /api/v1/eventos (SSE) avisa cada cambio de etapa de las peticiones, sin su contenido. Con la clave de una API, solo las suyas.Yes: GET /api/v1/eventos (SSE) reports every stage change of the requests, without their content. With an API’s key, only its own.

Qué esWhat it is

El mismo Tramtai, instalado como servicio del sistema en Linux con systemd o en Windows Server (también Server Core). Tiene su propia cuenta, sin privilegios, sus datos en una carpeta del sistema y su propio puerto. macOS no tiene servicio del sistema: allí está «Solo el servicio», que arranca al iniciar sesión.

Es un servidor personal, con un solo administrador. Se abre desde otros equipos solo por HTTPS, con la contraseña del administrador y, si quieres, un segundo factor (TOTP). Varias cuentas o permisos por persona no están en esta versión.

The same Tramtai, installed as a system service on Linux with systemd or Windows Server (Server Core too). It has its own unprivileged account, its data in a system folder and its own port. macOS has no system service: there you have “Just the service”, which starts when you sign in.

It’s a personal server with a single administrator. It opens from other computers over HTTPS only, with the administrator password and, if you want, a second factor (TOTP). Several accounts or per-person permissions aren’t in this version.

Dos entornosTwo environments

Tu Tramtai y el del servidor no comparten nada: cada uno tiene sus espacios, APIs, claves, sesiones de los CLI, historial y ajustes. Una API de tu equipo no existe en el servidor, ni al revés. La cabecera de la Web UI y la terminal dicen siempre en cuál estás: «Servidor» o «Este equipo».

InstalarInstall

Linux. Descarga de Releases el .tar.gz de tu arquitectura (amd64 o arm64) y SHA256SUMS.txt, comprueba la suma e instala como root. O instala el paquete del servidor (Tramtai-…-servidor-linux-….deb o .rpm), que convive con el de escritorio, y después sudo tramtai-servidor instalar: el paquete por sí solo no arranca nada, porque antes tienes que aceptar los términos.

Windows Server. Descomprime el .zip portable y, en una consola de administrador, .\tramtai.exe servidor instalar. Crea el servicio «Tramtai (servidor)» con su cuenta virtual y deja tramtai-servidor en el PATH del sistema.

Al terminar, te dice cómo seguir: la contraseña del administrador, el HTTPS (o un proxy) y las claves de los agentes. Repetir la instalación es seguro.

Linux. Download your architecture’s .tar.gz (amd64 or arm64) and SHA256SUMS.txt from Releases, check the sum and install as root. Or install the server package (Tramtai-…-servidor-linux-….deb or .rpm), which lives next to the desktop one, and then sudo tramtai-servidor install: the package alone starts nothing, because you have to accept the terms first.

Windows Server. Unzip the portable .zip and, in an administrator console, run .\tramtai.exe server install. It creates the “Tramtai (servidor)” service with its virtual account and puts tramtai-servidor on the system PATH.

When it finishes, it tells you what’s next: the administrator password, HTTPS (or a proxy) and the agents’ keys. Running the install again is safe.

sha256sum -c --ignore-missing SHA256SUMS.txt
tar xzf tramtai-*-linux-amd64.tar.gz && cd tramtai
sudo ./tramtai servidor instalarsudo ./tramtai server install
sudo tramtai-servidor administrador contraseñasudo tramtai-servidor admin password

Abrir a la redOpen to the network

Al instalarlo, el servidor solo atiende a este mismo equipo. Para usarlo desde otros, siempre con HTTPS: si lo abres a la red sin él, no arranca, porque tus claves viajarían sin cifrar. Hay tres formas:

  • Detrás de un proxy (la recomendada): el que ya uses pone el HTTPS y Tramtai sigue atendiendo solo a este equipo. Hay un ejemplo listo para cada uno. Si no es uno de estos, el proxy tiene que usar TLS 1.3, enviar X-Forwarded-Proto, conservar el Host y no guardar las respuestas en búfer.
  • Con tu certificado: Tramtai pone su propio HTTPS, solo con TLS 1.3, y vuelve a leer el certificado cuando lo renuevas.
  • Con Let’s Encrypt: Tramtai saca y renueva el certificado solo, por el puerto 443.

Túneles: Cloudflare Tunnel y Tailscale Serve o Funnel publican el servidor sin abrir puertos (cómo). Con Cloudflare, el HTTPS termina en Cloudflare, que ve tus peticiones y tus claves, y corta a los 125 s una respuesta que no ha empezado: en las peticiones largas, pide la respuesta en vivo. Cloudflare Tunnel y Tailscale Serve: sin comprobar a mano todavía.

En tu red local: tampoco hay HTTP plano. Tailscale Serve, Caddy con su CA interna, un certificado de tu propia CA (por ejemplo, con mkcert) o un túnel SSH, en Red local (homelab).

En el propio servidor: tramtai-servidor abrir, la tecla W de la terminal y la app entran directamente. Con un proxy de confianza, abrir a mano el puerto de Tramtai en el navegador del servidor cuenta como entrar desde fuera, y desde fuera no se entra sin la contraseña del administrador.

After installing, the server only serves this same computer. To use it from others, always with HTTPS: if you open it to the network without it, it won’t start, because your keys would travel unencrypted. There are three ways:

  • Behind a proxy (recommended): the one you already use provides HTTPS and Tramtai keeps serving only this computer. There’s a ready example for each. For any other proxy, it must use TLS 1.3, send X-Forwarded-Proto, keep the Host and not buffer responses.
  • With your own certificate: Tramtai provides its own HTTPS, TLS 1.3 only, and reads the certificate again when you renew it.
  • With Let’s Encrypt: Tramtai gets and renews the certificate itself, over port 443.

Tunnels: Cloudflare Tunnel and Tailscale Serve or Funnel publish the server without opening ports (how). With Cloudflare, HTTPS ends at Cloudflare, which sees your requests and your keys, and it cuts a response that hasn’t started within 125 s: for long requests, ask for the streamed response. Cloudflare Tunnel and Tailscale Serve: not yet checked by hand.

On your local network: there’s no plain HTTP either. Tailscale Serve, Caddy with its internal CA, a certificate from your own CA (for example, with mkcert) or an SSH tunnel, in Local network (homelab).

On the server itself: tramtai-servidor open, the terminal’s W key and the app get in directly. With a trusted proxy, opening Tramtai’s port by hand in the server’s browser counts as coming from outside, and nobody gets in from outside without the administrator password.

AdministradorAdministrator

La contraseña del administrador (12 caracteres o más) se pone en el servidor con tramtai-servidor administrador contraseña; de ella solo se guarda una huella. El segundo factor (TOTP), con su app de autenticación y 10 códigos de recuperación, se activa con … administrador totp activar o, en Windows, también en Ajustes → Seguridad. Tras 5 intentos fallidos, esa dirección espera 15 minutos, y la sesión caduca tras 12 horas sin uso.

Ajustes → Servidor enseña cómo se llega al servidor (HTTPS, dominios, proxies, certificado) con la orden que cambia cada dato. No se cambia desde la Web UI: un error de red te dejaría fuera.

Set the administrator password (12 characters or more) on the server with tramtai-servidor admin password; only a hash of it is stored. The second factor (TOTP), with your authenticator app and 10 recovery codes, is turned on with … admin totp enable or, on Windows, also in Settings → Security. After 5 failed attempts, that address waits 15 minutes, and sessions expire after 12 hours idle.

Settings → Server shows how the server is reached (HTTPS, domains, proxies, certificate) with the command that changes each item. It isn’t changed from the Web UI: a network mistake would lock you out.

Claves y suscripciónKeys and subscription

Las claves de los agentes se guardan cifradas, en el servidor y con la CLI (tramtai-servidor claves guardar ANTHROPIC_API_KEY), nunca desde la Web UI. Los CLI de los agentes tienen que estar instalados para todo el equipo, y los ejecuta el servicio con su propia cuenta.

Tu suscripción: por defecto el servidor usa claves de API. Abierto a la red, solo admite tu suscripción personal: solo para ti, con TOTP y una petición a la vez (por defecto; hasta 3 con suscripcion_simultaneas), y el aviso «Este servidor usa tu suscripción de…» siempre a la vista. Tu proveedor puede limitar o cerrar tu cuenta igualmente (riesgo 1).

Codex en el servidor: Codex puede leer todo lo que lee la cuenta del servicio, también las claves de los proveedores y el secreto del TOTP. Da la clave del espacio, y la de cualquier API que pueda usar Codex, solo a personas de confianza. En las APIs de otras personas, pon en Modelos permitidos solo agentes que no son Codex (vacía, deja usar cualquiera) y no pongas Codex en su respaldo, o desconecta Codex.

Agents’ keys are stored encrypted, on the server and with the CLI (tramtai-servidor keys set ANTHROPIC_API_KEY), never from the Web UI. The agents’ CLIs must be installed for the whole computer, and the service runs them with its own account.

Your subscription: by default the server uses API keys. Open to the network, it only allows your personal subscription: just for you, with TOTP and one request at a time (by default; up to 3 with suscripcion_simultaneas), and the “This server uses your … subscription” notice always visible. Your provider may still limit or close your account (risk 1).

Codex on the server: Codex can read everything the service account reads, including the provider keys and the TOTP secret. Give the workspace key, and the key of any API that can use Codex, only to people you trust. In other people’s APIs, put only agents other than Codex in Allowed models (left empty, it allows any) and keep Codex out of their fallback, or disconnect Codex.

Actualizar y quitarUpdate and remove

El servidor avisa cuando hay una versión nueva. tramtai-servidor actualizar comprueba la firma de Tramtai, deja terminar las peticiones en curso y cambia el programa; si lo instalaste con el paquete, actualiza con apt o dnf. tramtai-servidor desinstalar lo quita y conserva tus datos; --borrar-datos borra también los datos, las claves y la cuenta.

The server tells you when there’s a new version. tramtai-servidor update checks Tramtai’s signature, lets running requests finish and swaps the program; if you installed the package, update with apt or dnf. tramtai-servidor uninstall removes it and keeps your data; --delete-data also deletes the data, the keys and the account.

Si algo fallaIf something fails

  • No arranca: tramtai-servidor estado y tramtai-servidor registro dicen qué regla no se cumple y qué cambiar.
  • «Aquí no se entra con contraseña»: la conexión no llega por HTTPS, o el proxy no envía X-Forwarded-Proto: https o no está entre los de confianza.
  • La CLI dice que el servidor es de otra versión: tramtai-servidor actualizar; la CLI nunca lo detiene por ti.

La guía completa del servidor, con la configuración de cada caso, y la Ayuda: Modo servidor y Dos entornos.

  • It won’t start: tramtai-servidor status and tramtai-servidor log say which rule fails and what to change.
  • “You can’t sign in with a password here”: the connection isn’t HTTPS, or the proxy doesn’t send X-Forwarded-Proto: https or isn’t trusted.
  • The CLI says the server is another version: tramtai-servidor update; the CLI never stops it for you.

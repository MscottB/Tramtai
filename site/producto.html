Tus agentes de IA, una sola API local.Your AI agents, one local API.

Tres paradas y tu app ya habla con un agente.Three stops and your app is talking to an agent.

  1. Instala TramtaiInstall Tramtai

    En Windows, macOS o Linux. Queda en la bandeja del sistema con el servicio en marcha.On Windows, macOS or Linux. It sits in the system tray with the service running.

  2. Conecta un agenteConnect an agent

    Usa tu suscripción de Claude, ChatGPT o GitHub Copilot para uso personal, o una clave de API. Si no tienes su CLI, Tramtai lo instala y te ayuda a iniciar sesión.Use your Claude, ChatGPT or GitHub Copilot subscription for personal use, or an API key. If you don’t have its CLI, Tramtai installs it and helps you sign in.

  3. Apunta tu aplicaciónPoint your app

    Cambia la URL base de tu SDK de OpenAI o Anthropic y elige agente y modelo en el campo model.Change the base URL of your OpenAI or Anthropic SDK and pick agent and model in the model field.

    A Claude Code, Codex, Continue, opencode y Kilo los apunta Tramtai por ti, en Mis APIs → Herramientas: antes guarda una copia de su configuración, y un interruptor los deja como estaban. Conectar tus herramientasTramtai points Claude Code, Codex, Continue, opencode and Kilo at itself for you, in My APIs → Tools: it first saves a copy of their configuration, and a switch puts them back as they were. Connect your tools

from openai import OpenAI

# La URL y la clave están en Tramtai → Mis APIs# The URL and the key are in Tramtai → My APIs
clienteclient = OpenAI(base_url="http://127.0.0.1:17373/openai/v1", api_key="tu-clave-de-tramtaiyour-tramtai-key")

# La respuesta llega en vivo, trozo a trozo# The response arrives live, chunk by chunk
flujostream = clienteclient.chat.completions.create(
    model="claude/sonnet", stream=True,
    messages=[{"role": "user", "content": "Explica este error en dos frasesExplain this error in two sentences"}],
)
for trozochunk in flujostream:
    print(trozochunk.choices[0].delta.content or "", end="")
import anthropic

# La URL y la clave están en Tramtai → Mis APIs# The URL and the key are in Tramtai → My APIs
clienteclient = anthropic.Anthropic(base_url="http://127.0.0.1:17373/anthropic", api_key="tu-clave-de-tramtaiyour-tramtai-key")

respuestaresponse = clienteclient.messages.create(
    model="claude/haiku", max_tokens=1024,
    messages=[{"role": "user", "content": "Resume este contrato en tres puntosSummarize this contract in three points"}],
)
print(respuestaresponse.content[0].text)
# La misma petición por la URL compatible con OpenAI# The same request through the OpenAI-compatible URL
curl http://127.0.0.1:17373/openai/v1/chat/completions \
  -H "Authorization: Bearer tu-clave-de-tramtaiyour-tramtai-key" -H "Content-Type: application/json" \
  -d '{"model": "claude/haiku", "messages": [{"role": "user", "content": "Resume este contrato en tres puntosSummarize this contract in three points"}]}'

Una red con una línea por agente.A network with one line per agent.

En la app, cada petición viaja en vivo por la línea de su agente. Aquí, cada línea es lo que hace Tramtai: conectar, controlar, proteger y usar, con tres paradas cada una.In the app, every request travels live along its agent’s line. Here, each line is what Tramtai does: connect, control, protect and use, with three stops each.

ConectaConnect

  1. Compatible con tus SDKWorks with your SDKs

    Rutas compatibles con OpenAI (chat y responses) y Anthropic (messages) con respuesta en vivo (streaming), más una API propia con eventos en vivo. Las tres admiten herramientas (tools).OpenAI-compatible (chat and responses) and Anthropic-compatible (messages) routes with live responses (streaming), plus a native API with live events. All three support tool calling (tools).

  2. API propia con OpenAPINative API with OpenAPI

    Con /api/v1 sigues, cancelas y reintentas cada petición. Trae su especificación OpenAPI, y «Ver como código» te da la petición lista en curl, Python o Node.With /api/v1 you follow, cancel and retry every request. It ships its OpenAPI spec, and “View as code” gives you the request ready in curl, Python or Node.

  3. Respuestas con formaShaped responses

    Elige una plantilla o arma los campos, sin escribir JSON Schema. Tramtai valida la respuesta, te dice qué campo falló y «Corregir» le pide al agente que la arregle.Pick a template or build the fields, without writing JSON Schema. Tramtai validates the response, tells you which field failed, and “Correct” asks the agent to fix it.

ControlaControl

  1. Espacios de trabajoWorkspaces

    El espacio global y uno por proyecto: cada uno guarda sus datos aparte. Los Ajustes muestran qué viene de todo Tramtai, y una carpeta clonada pregunta antes de aplicar su configuración.The global workspace and one per project: each keeps its data apart. Settings show what comes from all of Tramtai, and a cloned folder asks before applying its configuration.

  2. Una API por aplicaciónOne API per app

    Crea varias APIs con su propia clave, los modelos permitidos, instrucciones fijas y un presupuesto diario o mensual que frena las peticiones al llegar al límite. Actívalas o detenlas sin reiniciar.Create several APIs, each with its own key, allowed models, fixed instructions and a daily or monthly budget that stops requests at the limit. Turn them on or off without restarting.

  3. Modelo y esfuerzo en cada peticiónModel and effort per request

    Elige modelo en cada petición y, en los agentes que lo admiten, cuánto razona: de bajo a máximo.Pick the model per request and, with the agents that support it, how hard it reasons: from low to maximum.

ProtegeProtect

  1. Respaldo entre agentesAgent fallback

    Si le das una lista de respaldo y el agente llega a su límite o falla antes de responder, la petición sigue con el siguiente de la lista que esté conectado.If you give it a fallback list and the agent hits its limit or fails before answering, the request continues with the next connected agent on the list.

  2. Claves cifradas en el almacén del sistemaKeys encrypted in the system store

    Tus claves de proveedor quedan cifradas en el almacén del sistema, y las de tus APIs y de tus espacios se ven una sola vez, solo se guarda su huella, y se regeneran con un clic si se filtran. La clave que Tramtai da a Continue, opencode o Kilo Code va además en el archivo de cada herramienta, dentro de tu carpeta de usuario.Your provider keys stay encrypted in the system store, and the keys of your APIs and workspaces are shown only once, only a hash of them is stored, and they can be regenerated in one click if they leak. The key Tramtai gives Continue, opencode or Kilo Code also goes in each tool’s file, inside your user folder.

  3. Sin terminal ni webNo terminal, no web

    Claude Code y GitHub Copilot van sin herramientas; Codex, en solo lectura y sin terminal ni búsqueda web. Por defecto cada uno trabaja en una carpeta temporal vacía y no recibe las claves de los demás.Claude Code and GitHub Copilot run without tools; Codex runs read-only, with no terminal or web search. By default each one works in an empty temporary folder and doesn’t get the other agents’ keys.

UsaUse

  1. La terminal, a la par de la appThe terminal, on par with the app

    Las ocho páginas de la app en tramtai terminal, con el teclado, sin abrir la app y por SSH. La bandeja, la app en tu navegador (en español e inglés), la terminal y la CLI ven las mismas peticiones.The app’s eight pages in tramtai terminal, all from the keyboard, without the app open and over SSH. The tray, the app in your browser (in Spanish and English), the terminal and the CLI all see the same requests.

  2. Adjunta PDF, Word y ExcelAttach PDF, Word and Excel

    Adjunta PDF, Word, Excel, PowerPoint, HTML o texto: Tramtai los convierte a texto antes de pasarlos al agente.Attach PDF, Word, Excel, PowerPoint, HTML or text files: Tramtai turns them into text before handing them to the agent.

  3. Recorrido y AyudaTour and Help

    Un recorrido guiado te señala cada parte de la app (míralo paso a paso), y un «?» en cada página abre su Ayuda, con qué hacer junto a cada error. La misma Ayuda está en esta web.A guided tour points at each part of the app (see it step by step), and a “?” on every page opens its Help, with what to do next to each error. The same Help is on this website.

PrivacidadPrivacy

Tramtai no tiene servidor propio.Tramtai has no server of its own.

Funciona en tu equipo y no tiene cuentas. Tus peticiones van de tu equipo al proveedor del agente que elijas, no a Tramtai.It runs on your computer and has no accounts. Your requests go from your computer to the provider of the agent you choose, not to Tramtai.

  • RedNetworkPor defecto escucha solo en 127.0.0.1; abrirlo a otros equipos es un ajuste aparte, apagado de serie, y solo arranca con HTTPS. Cada API exige su propia clave.By default it listens only on 127.0.0.1; opening it to other computers is a separate setting, off out of the box, and it only starts with HTTPS. Every API requires its own key.
  • ClavesKeysTus claves de proveedor quedan cifradas en el almacén del sistema, no en los archivos de Tramtai. La clave de cada API y la de cada espacio solo se ven al crearlas o regenerarlas, Tramtai guarda solo su huella y no sirven para abrir la app.Your provider keys are encrypted in the system store, not in Tramtai’s files. Each API’s key and each workspace’s key are shown only when they are created or regenerated, Tramtai stores only a hash of them and they can’t open the app.
  • SesionesSessionsTramtai no lee las credenciales de los CLI: les pregunta con qué cuenta iniciaste sesión. Con GitHub Copilot copia a su carpeta privada qué cuenta es, sin su clave.Tramtai doesn’t read the CLIs’ credentials: it asks them which account you signed in with. With GitHub Copilot it copies which account it is to its private folder, without its key.
  • DatosDataLas respuestas se guardan 24 horas por defecto; lo cambias en Ajustes, donde también vacías el historial.Responses are kept for 24 hours by default; you change that in Settings, where you can also clear the history.
  • TelemetríaTelemetryNinguna. Tramtai no envía estadísticas de uso. Solo consulta GitHub para buscar versiones nuevas, y eso se apaga en Ajustes.None. Tramtai sends no usage statistics. It only checks GitHub for new versions, and you can turn that off in Settings.

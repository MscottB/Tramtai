EmpezarGet started

Necesitas Tramtai en marcha con al menos un agente conectado, y la URL y la clave de tu API (en la app, Mis APIs). Los ejemplos las leen de tres variables: TRAMTAI_URL (por defecto http://127.0.0.1:17373), TRAMTAI_CLAVE y TRAMTAI_MODELO (agente y modelo, por defecto claude/haiku).

¿Qué API uso? Si tu app ya usa el SDK de OpenAI o el de Anthropic, su URL (/openai/v1 o /anthropic): no cambias nada más. Si necesitas trabajos largos que sigues, cancelas o reintentas, la API propia (/api/v1). La ayuda compara las tres.

  • Python: pip install openai requests
  • JavaScript (Node 20+): npm install openai
  • Go: go get github.com/openai/openai-go/v3
  • curl: los ejemplos que encadenan pasos usan jq.

Todos los ejemplos están en docs/ejemplos y el CI los ejecuta en cada cambio.

You need Tramtai running with at least one agent connected, plus your API's URL and key (in the app, My APIs). The examples read them from three variables: TRAMTAI_URL (default http://127.0.0.1:17373), TRAMTAI_CLAVE and TRAMTAI_MODELO (agent and model, default claude/haiku).

Which API? If your app already uses the OpenAI or Anthropic SDK, its URL (/openai/v1 or /anthropic): nothing else changes. If you need long jobs you follow, cancel or retry, the native API (/api/v1). Help compares all three.

ArchivosFiles

Se admiten PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx) y HTML, que Tramtai convierte a texto, y texto tal cual (.txt, .md, .json, .csv, .xml, .yaml…). Por OpenAI y Anthropic el archivo va en base64 dentro del mensaje (hasta unos 12 MB en total); por la API propia se sube a /cargas (hasta 50 MB cada uno) y el trabajo lo cita. La lista exacta está en GET /api/v1/limites.

Accepted: PDF, Word (.docx), PowerPoint (.pptx), Excel (.xlsx) and HTML, which Tramtai turns into text, and plain text as is (.txt, .md, .json, .csv, .xml, .yaml…). Through OpenAI and Anthropic the file goes in base64 inside the message (about 12 MB in total); through the native API you upload it to /cargas (up to 50 MB each) and the job cites it. The exact list is at GET /api/v1/limites.

HerramientasTool calling

Las herramientas (tools) son funciones de tu aplicación: consultar un pedido, buscar en tu base de datos, mirar el tiempo. Se las describes al agente; si las necesita, pide la llamada con sus argumentos, tu app la ejecuta y le devuelve el resultado en el turno siguiente. El agente nunca ejecuta nada: solo pide.

Tools are functions of your app: look up an order, search your database, check the weather. You describe them to the agent; if it needs one, it asks for the call with its arguments, your app runs it and sends back the result in the next turn. The agent never runs anything: it only asks.

  1. Tu app ofrece funcionesYour app offers functions
  2. El agente pide unaThe agent asks for one
  3. Tu app la ejecutaYour app runs it
  4. Le devuelve el resultadoIt sends back the result
  5. El agente respondeThe agent answers

Por la URL de Anthropic

Igual que con su SDK: tools con input_schema, bloques tool_use en la respuesta y tool_result en el mensaje siguiente.

Lo que conviene saber

  • Los argumentos llegan validados con el JSON Schema de cada herramienta; si el agente se equivoca, Tramtai le pide que corrija (con las correcciones de la petición o de la receta) antes de responder.
  • Con herramientas, la respuesta llega completa al terminar, aunque pidas stream.
  • No se combinan con una respuesta en JSON, y van en cada petición: las recetas no las guardan.

Through the Anthropic URL

Just like with its SDK: tools with input_schema, tool_use blocks in the answer and tool_result in the next message.

Good to know

  • Arguments arrive validated against each tool's JSON Schema; if the agent gets them wrong, Tramtai asks it to fix them (with the request's or the recipe's corrections) before answering.
  • With tools, the answer arrives complete at the end, even if you ask for stream.
  • They can't be combined with a JSON answer, and they go in every request: recipes don't store them.

Trabajos largosLong jobs

Solo por la API propia: creas el trabajo, lo sigues en vivo por eventos (si se corta la conexión, retomas con Last-Event-ID) y lees el resultado. POST /trabajos/{id}/cancelar lo detiene y POST /trabajos/{id}/reintentar lo vuelve a lanzar.

Native API only: you create the job, follow it live through events (if the connection drops, resume with Last-Event-ID) and read the result. POST /trabajos/{id}/cancelar stops it and POST /trabajos/{id}/reintentar runs it again.

Errores y reintentosErrors and retries

Los errores llegan en el formato de la API que usas, con un code estable. Para reintentar sin duplicar un trabajo, envía la cabecera Idempotency-Key: la misma clave con la misma petición devuelve el mismo trabajo (en las tres APIs).

HTTPCódigoQué hacer
400solicitud_invalida, parametro_no_soportado, carga_invalidaCorrige la petición: el mensaje dice qué campo falla.
401no_autorizadoRevisa la clave (Mis APIs); si la regeneraste, la anterior ya no vale.
409conflicto_idempotenciaEsa Idempotency-Key ya se usó con otra petición: usa otra.
422salida_no_cumple_esquemaLa respuesta o las llamadas no cumplían el esquema: pide correcciones o «Corregir».
429cola_llena, presupuesto_agotado, limite_uso_proveedorEspera lo que diga Retry-After y reintenta.
502error_agente, autenticacion_agenteEl agente falló o no tiene sesión: revisa Agentes en la app.
503agente_no_disponible, conversor_no_disponibleAlgo no está listo; con Retry-After, reintenta después.

Errors arrive in the format of the API you use, with a stable code. To retry without duplicating a job, send the Idempotency-Key header: the same key with the same request returns the same job (on all three APIs).

HTTPCodeWhat to do
400solicitud_invalida, parametro_no_soportado, carga_invalidaFix the request: the message says which field fails.
401no_autorizadoCheck the key (My APIs); if you regenerated it, the old one no longer works.
409conflicto_idempotenciaThat Idempotency-Key was used with another request: use a new one.
422salida_no_cumple_esquemaThe answer or the calls did not match the schema: ask for corrections or «Correct».
429cola_llena, presupuesto_agotado, limite_uso_proveedorWait for Retry-After and retry.
502error_agente, autenticacion_agenteThe agent failed or has no session: check Agents in the app.
503agente_no_disponible, conversor_no_disponibleSomething is not ready; with Retry-After, retry later.
